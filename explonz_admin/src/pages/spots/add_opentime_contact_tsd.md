### spots 表（当前）
缺少 `phone`、`website` 字段。

### spot_opening_hours 表（当前）
已存在，结构满足需求，**无需修改**：
- `day_of_week SMALLINT`（0=Sunday … 6=Saturday）支持每天独立配置
- `is_closed / is_open_24h` 互斥标志
- `open_time / close_time TIME` 支持跨午夜（close_time < open_time 视为跨天）
- `UNIQUE (spot_id, day_of_week)` 保证每天只有一条记录

### 4.2 `src/service/spots.rs`（完整文件）

`create_spot_service` 使用事务，在一次原子操作中完成 spot + opening_hours 写入。

`open_time` / `close_time` 字段类型为 `chrono::NaiveTime`，需用 `NaiveTime::parse_from_str` 将 "HH:MM" 字符串转换。

```rust
use chrono::NaiveTime;
use explonz_shared::common::dto::SpotDto;
use sea_orm::{ActiveModelTrait, ActiveValue::Set, DatabaseConnection, TransactionTrait};

use crate::api::spots::dto::CreateSpotRequest;
use explonz_shared::entity::{spot_opening_hours, spots};

pub async fn create_spot_service(
    db: &DatabaseConnection,
    req: CreateSpotRequest,
) -> anyhow::Result<SpotDto> {
    let spot_name = req.name.clone();

    let result = db
        .transaction::<_, SpotDto, anyhow::Error>(|txn| {
            Box::pin(async move {
                // 1. INSERT spot
                let spot = spots::ActiveModel {
                    name: Set(req.name),
                    location: Set(req.location),
                    latitude: Set(req.latitude),
                    longitude: Set(req.longitude),
                    description: Set(req.description),
                    photo_urls: Set(req.photo_urls),
                    attributes: Set(req.attributes),
                    phone: Set(req.phone),
                    website: Set(req.website),
                    ..Default::default()
                }
                .insert(txn)
                .await?;

                // 2. 批量 INSERT opening_hours
                for oh in req.opening_hours {
                    let open_time = oh
                        .open_time
                        .map(|t| NaiveTime::parse_from_str(&t, "%H:%M"))
                        .transpose()
                        .map_err(|e| anyhow::anyhow!("Invalid open_time: {e}"))?;
                    let close_time = oh
                        .close_time
                        .map(|t| NaiveTime::parse_from_str(&t, "%H:%M"))
                        .transpose()
                        .map_err(|e| anyhow::anyhow!("Invalid close_time: {e}"))?;

                    spot_opening_hours::ActiveModel {
                        spot_id: Set(spot.id),
                        day_of_week: Set(oh.day_of_week),
                        is_closed: Set(oh.is_closed),
                        is_open_24h: Set(oh.is_open_24h),
                        open_time: Set(open_time),
                        close_time: Set(close_time),
                        ..Default::default()
                    }
                    .insert(txn)
                    .await?;
                }

                Ok(SpotDto {
                    id: spot.id,
                    name: spot.name,
                    rating: spot.rating,
                    location: spot.location,
                    latitude: spot.latitude,
                    longitude: spot.longitude,
                    description: spot.description,
                    photo_urls: spot.photo_urls,
                    attributes: spot.attributes,
                    created_at: spot.created_at.into(),
                    updated_at: spot.updated_at.into(),
                    phone: spot.phone,
                    website: spot.website,
                })
            })
        })
        .await?;

    tracing::info!("spot created: {}", spot_name);
    Ok(result)
}
```

> **注意**：`SpotDto::from(spot)` 无法直接使用（`crate::entity::spots::Model` 与 `explonz_shared::entity::spots::Model` 是不同类型），需手动构造 `SpotDto`。

```rust
#[server(CreateSpot, "/api")]
pub async fn create_spot(
    name: String,
    location: String,
    latitude: f64,
    longitude: f64,
    description: String,
    photo_urls: Vec<String>,
    attributes_json: String,
    phone: Option<String>,
    website: Option<String>,
    opening_hours_json: String, // 由 UI 隐藏字段自动维护，见 addition.rs
) -> Result<SpotDto, ServerFnError> {
    use axum_extra::extract::CookieJar;
    use leptos_axum::extract;

    // 1. 取出 access_token cookie 作为 Bearer token
    let jar: CookieJar = extract().await?;
    let token = jar
        .get("access_token")
        .map(|c| c.value().to_string())
        .ok_or_else(|| ServerFnError::new("Not authenticated"))?;

    // 2. 过滤空值
    let photo_urls: Vec<String> = photo_urls
        .into_iter()
        .filter(|s| !s.trim().is_empty())
        .collect();

    // 3. 解析 attributes JSON，为空时默认 []
    let attributes: serde_json::Value = if attributes_json.trim().is_empty() {
        serde_json::Value::Array(vec![])
    } else {
        serde_json::from_str(&attributes_json)
            .map_err(|e| ServerFnError::new(format!("Invalid JSON: {e}")))?
    };

    // 4. 解析 opening_hours JSON，为空时默认 []
    let opening_hours: serde_json::Value = if opening_hours_json.trim().is_empty() {
        serde_json::Value::Array(vec![])
    } else {
        serde_json::from_str(&opening_hours_json)
            .map_err(|e| ServerFnError::new(format!("Invalid opening hours JSON: {e}")))?
    };

    // 5. 构造请求体
    let body = serde_json::json!({
        "name": name,
        "location": location,
        "latitude": latitude,
        "longitude": longitude,
        "description": description,
        "photo_urls": photo_urls,
        "attributes": attributes,
        "phone": phone,
        "website": website,
        "opening_hours": opening_hours,
    });

    // 6. 转发请求到后端（携带 Bearer token）
    let backend_url =
        std::env::var("BACKEND_URL").unwrap_or_else(|_| "http://127.0.0.1:3000".to_string());

    let resp = reqwest::Client::new()
        .post(format!("{backend_url}/api/spots/new"))
        .bearer_auth(&token)
        .json(&body)
        .send()
        .await
        .map_err(|e| ServerFnError::new(e.to_string()))?;

    // 7. 处理响应
    if !resp.status().is_success() {
        let msg = resp.text().await.unwrap_or_default();
        return Err(ServerFnError::new(format!("Backend error: {msg}")));
    }

    #[derive(serde::Deserialize)]
    struct BackendResponse {
        data: Option<SpotDto>,
    }

    let parsed: BackendResponse = resp
        .json()
        .await
        .map_err(|e| ServerFnError::new(e.to_string()))?;

    parsed
        .data
        .ok_or_else(|| ServerFnError::new("No data returned"))
}

#[server(GeocodeLocation, "/api")]
pub async fn geocode_location(address: String) -> Result<(f64, f64), ServerFnError> {
    use serde::Deserialize;

    #[derive(Deserialize)]
    struct NominatimResult {
        lat: String,
        lon: String,
    }

    let results: Vec<NominatimResult> = reqwest::Client::new()
        .get("https://nominatim.openstreetmap.org/search")
        .query(&[("q", address.as_str()), ("format", "json"), ("limit", "1")])
        .header("User-Agent", "explonz-admin/1.0")
        .send()
        .await
        .map_err(|e| ServerFnError::new(e.to_string()))?
        .json()
        .await
        .map_err(|e| ServerFnError::new(e.to_string()))?;

    let result = results
        .into_iter()
        .next()
        .ok_or_else(|| ServerFnError::new("No location found for this address"))?;

    Ok((
        result.lat.parse::<f64>().map_err(|e| ServerFnError::new(e.to_string()))?,
        result.lon.parse::<f64>().map_err(|e| ServerFnError::new(e.to_string()))?,
    ))
}
```

### 5.2 `explonz_admin/src/pages/spots/addition.rs`（完整文件）

新增内容：
- Phone / Website 可选输入框（双列布局）
- 7 天营业时间编辑器，含 `DaySchedule` 状态设计、`Memo<String>` 隐藏字段序列化、快捷复制按钮

**关键设计要点：**

| 要点 | 说明 |
|------|------|
| `DaySchedule` | 每天一个结构体，含 `status / open_time / close_time` 三个 RwSignal |
| `StoredValue` | 7 个 `DaySchedule` 存入 `StoredValue<Vec<...>>`，避免在闭包中 move 整个 Vec |
| `Memo<String>` | 依赖所有 signal，任意变化时重新序列化为 JSON |
| 隐藏字段 | `<input type="hidden" name="opening_hours_json" prop:value=move \|\| hours_memo.get() />`，ActionForm 提交时自动携带 |
| 快捷按钮 | 不触发表单提交，只更新 signal |

```rust
use icons::Trash2;
use leptos::prelude::*;
use leptos_router::hooks::use_navigate;
use leptos_router::NavigateOptions;
use serde::Serialize;

use crate::components::ui::button::{Button, ButtonVariant};
use crate::components::ui::card::{Card, CardContent, CardHeader, CardTitle};
use crate::components::ui::input::{Input, InputType};
use crate::components::ui::label::Label;
use crate::server::spots::{geocode_location, CreateSpot};

const TEXTAREA_CLASS: &str = "text-foreground placeholder:text-muted-foreground border-input \
    flex w-full rounded-md border bg-transparent px-3 py-2 text-sm shadow-xs outline-none \
    focus-visible:border-ring focus-visible:ring-ring/50 focus-visible:ring-2 \
    dark:bg-input/30 resize-none";

#[derive(Clone, PartialEq)]
enum DayStatus {
    Open,
    Closed,
    Open24h,
}

struct DaySchedule {
    status: RwSignal<DayStatus>,
    open_time: RwSignal<String>,
    close_time: RwSignal<String>,
}

/// 序列化到后端的结构（与后端 OpeningHourInput 对应）
#[derive(Serialize)]
struct OpeningHourJson {
    day_of_week: i16,
    is_closed: bool,
    is_open_24h: bool,
    open_time: Option<String>,
    close_time: Option<String>,
}

#[component]
pub fn SpotAddition() -> impl IntoView {
    let create_action = ServerAction::<CreateSpot>::new();
    let navigate = use_navigate();
    let navigate_cancel = navigate.clone();

    // 动态 Photo URL 行：使用稳定 ID 避免删除时索引偏移导致 For key 错误
    let next_id = RwSignal::new(1u32);
    let photo_rows: RwSignal<Vec<(u32, RwSignal<String>)>> =
        RwSignal::new(vec![(0, RwSignal::new(String::new()))]);

    // Location 文本绑定（用于 Lookup 按钮读取当前值）
    let location_val = RwSignal::new(String::new());
    // Lat / Lng 双向绑定，由 geocode 结果自动写入，也允许用户手动修改
    let lat = RwSignal::new(String::new());
    let lng = RwSignal::new(String::new());

    // 调用 geocode_location server fn 的 Action
    let geocode_action = Action::new(move |address: &String| {
        let address = address.clone();
        async move { geocode_location(address).await }
    });

    // geocode 成功后写入 lat / lng
    Effect::new(move |_| {
        if let Some(Ok((lat_val, lng_val))) = geocode_action.value().get() {
            lat.set(format!("{lat_val}"));
            lng.set(format!("{lng_val}"));
        }
    });

    // 7 天营业时间（0=Sun … 6=Sat）
    // 工作日默认 Open，周末默认 Closed
    let days: [(&'static str, DayStatus); 7] = [
        ("Sunday",    DayStatus::Closed),
        ("Monday",    DayStatus::Open),
        ("Tuesday",   DayStatus::Open),
        ("Wednesday", DayStatus::Open),
        ("Thursday",  DayStatus::Open),
        ("Friday",    DayStatus::Open),
        ("Saturday",  DayStatus::Closed),
    ];
    let schedules: Vec<(&'static str, DaySchedule)> = days
        .into_iter()
        .map(|(name, default_status)| {
            (name, DaySchedule {
                status: RwSignal::new(default_status),
                open_time: RwSignal::new("09:00".to_string()),
                close_time: RwSignal::new("17:00".to_string()),
            })
        })
        .collect();
    // StoredValue 避免在多个闭包中 move 整个 Vec
    let schedules = StoredValue::new(schedules);

    // Memo：响应式序列化所有 7 天为 JSON
    // 依赖所有 DaySchedule 的 signal，任意变化时自动重新计算
    let hours_memo = Memo::new(move |_| {
        let entries: Vec<OpeningHourJson> = schedules
            .get_value()
            .iter()
            .enumerate()
            .map(|(i, (_, s))| {
                let status = s.status.get();
                OpeningHourJson {
                    day_of_week: i as i16,
                    is_closed: status == DayStatus::Closed,
                    is_open_24h: status == DayStatus::Open24h,
                    open_time: if status == DayStatus::Open {
                        Some(s.open_time.get())
                    } else {
                        None
                    },
                    close_time: if status == DayStatus::Open {
                        Some(s.close_time.get())
                    } else {
                        None
                    },
                }
            })
            .collect();
        serde_json::to_string(&entries).unwrap_or_default()
    });

    // 提交成功后跳转列表页
    Effect::new(move |_| {
        if let Some(Ok(_)) = create_action.value().get() {
            navigate("/spots", NavigateOptions::default());
        }
    });

    view! {
        <div class="p-6 mx-auto">
            <h1 class="text-2xl font-semibold mb-6">"Create Spot"</h1>

            <Card>
                <CardHeader>
                    <CardTitle>"Spot Details"</CardTitle>
                </CardHeader>
                <CardContent>
                    <ActionForm action=create_action>
                        <div class="flex flex-col gap-5">

                            // Name
                            <div class="grid gap-2">
                                <Label html_for="name">"Name"</Label>
                                <Input id="name" name="name" placeholder="e.g. Kumeu Orchard" required=true />
                            </div>

                            // Location + Lookup 按钮
                            // bind_value=location_val 让输入框实时同步到 signal，
                            // 点击 Lookup 时通过 location_val.get_untracked() 读取当前地址
                            <div class="grid gap-2">
                                <Label html_for="location">"Location"</Label>
                                <div class="flex gap-2">
                                    <Input
                                        id="location"
                                        name="location"
                                        bind_value=location_val
                                        placeholder="e.g. Kumeu, Auckland"
                                        required=true
                                    />
                                    <Button
                                        variant=ButtonVariant::Outline
                                        attr:disabled=move || geocode_action.pending().get()
                                        on:click=move |_| {
                                            geocode_action.dispatch(location_val.get_untracked());
                                        }
                                    >
                                        {move || if geocode_action.pending().get() { "Looking up..." } else { "Lookup" }}
                                    </Button>
                                </div>
                                {move || geocode_action.value().get()
                                    .and_then(|r| r.err())
                                    .map(|e| view! {
                                        <p class="text-xs text-destructive">{e.to_string()}</p>
                                    })
                                }
                            </div>

                            // Latitude & Longitude（双列）
                            <div class="grid grid-cols-2 gap-4">
                                <div class="grid gap-2">
                                    <Label html_for="latitude">"Latitude"</Label>
                                    <Input r#type=InputType::Number id="latitude" name="latitude"
                                        placeholder="-36.7896" step="any" required=true bind_value=lat />
                                </div>
                                <div class="grid gap-2">
                                    <Label html_for="longitude">"Longitude"</Label>
                                    <Input r#type=InputType::Number id="longitude" name="longitude"
                                        placeholder="174.5432" step="any" required=true bind_value=lng />
                                </div>
                            </div>

                            // Description
                            <div class="grid gap-2">
                                <Label html_for="description">"Description"</Label>
                                <textarea id="description" name="description" rows="4"
                                    placeholder="Describe this spot..." class=TEXTAREA_CLASS />
                            </div>

                            // Photo URLs（动态增删行）
                            <div class="grid gap-2">
                                <Label>"Photo URLs"</Label>
                                <p class="text-xs text-muted-foreground">
                                    "First URL will be used as the cover image."
                                </p>

                                        each=move || photo_rows.get()
                                        key=|(id, _)| *id

                                                <div class="flex gap-2 items-center">
                                                    <Input name="photo_urls" bind_value=url_signal
                                                        placeholder="https://example.com/photo.jpg" />

                                                        variant=ButtonVariant::Ghost
                                                        attr:disabled=move || photo_rows.get().len() <= 1

                                                            photo_rows.update(|v| v.retain(|(row_id, _)| *row_id != id));
```

## 六、opening_hours_json 数据流转

```
UI signal (DaySchedule × 7)
    ↓ Memo 响应式序列化
JSON String（隐藏 input，bind_value=hours_memo）
    ↓ ActionForm 提交
server fn 参数 opening_hours_json: String
    ↓ serde_json::from_str
Vec<OpeningHourInput>（server fn 本地解析）
    ↓ serde_json::json! 嵌入请求体
reqwest POST /api/spots/new（JSON body，Bearer token）
    ↓ 后端反序列化 CreateSpotRequest
Vec<OpeningHourInput>（后端 DTO）
    ↓ TransactionTrait::transaction
spot_opening_hours 表（每天一行）
```

**各阶段说明：**

| 阶段 | 位置 | 说明 |
|------|------|------|
| UI signal | `addition.rs` | 7 个 `DaySchedule`，每个含 `status / open_time / close_time` RwSignal |
| Memo 序列化 | `addition.rs` | `Memo<String>` 依赖所有 signal，任意变化时自动重新序列化为 JSON |
| 隐藏字段 | `addition.rs` | `<input type="hidden" name="opening_hours_json" bind_value=hours_memo />`，ActionForm 提交时自动携带 |
| server fn 解析 | `server/spots.rs` | `serde_json::from_str(&opening_hours_json)` → `Vec<OpeningHourInput>` |
| reqwest 转发 | `server/spots.rs` | 解析结果嵌入 `serde_json::json!` body，`POST` 到后端（无需在 admin 定义 DTO 结构体） |
| 后端反序列化 | `src/api/spots/dto.rs` | `CreateSpotRequest { opening_hours: Vec<OpeningHourInput>, ... }` |
| 事务写库 | `src/service/spots.rs` | 先 INSERT spots，再遍历 opening_hours 批量 INSERT spot_opening_hours |
